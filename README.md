# Weather App MVP
- Creating a weather app that finds the weather of the location that you give it
- Outputs by the hour
    - temperature
    - wind gust 
    - percepitation
    - feels like temperature

# Additional Functionality
- Tells you the clothing you should be wearing based on the weather
- Articles of clothing that are considered for the user
    -headwear
    -inner
    -outter
    -bottoms
    -footwear
    -accessories (percipatation based)

# HTML input: 
    - user enters their location
    - user enters how many days of data they want
    -(optional) user gets auto alerts on what to wear at a user given time that are generated every day
